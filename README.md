# 🚀 Ausbildung Matcher AI

Ein intelligentes Web-Tool zur Bewertung der Übereinstimmung von Bewerberprofilen mit deutschen IT-Ausbildungspositionen (z. B. Fachinformatiker für Anwendungsentwicklung).

## 📌 Features
- 📊 **Matching Algorithm:** Berechnet einen präzisen Match-Score basierend auf Sprachniveau (CEFR), Qualifikation und IT-Skills.
- 💡 **Automatisches Feedback:** Erstellt maßgeschneiderte Empfehlungen zur Verbesserung der Bewerbungschancen.
- 🌐 **Web-Interface:** Einfache und benutzerfreundliche Benutzeroberfläche mit Flask und HTML.

## 🛠️ Tech Stack
- **Backend:** Python 3, Flask
- **Frontend:** HTML5, CSS3
